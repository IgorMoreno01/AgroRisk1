Objetivo

Adicionar filtros nas telas do Admin/Sompo para facilitar a navegação e a análise dos dados já exibidos, especialmente para casos como:

ver apenas máquinas com risco médio;
ver apenas itens com risco baixo/médio/alto/pendente;
filtrar por status, cliente, tipo, etc.

Também quero que, na tela de Operações monitoradas (print 5), exista:

uma área de filtros;
um botão de voltar para a Visão geral.
