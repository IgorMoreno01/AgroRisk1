As integrações das APIs do AgroRisk já foram implementadas no backend.

Agora quero que você faça a integração completa dessas informações com o FRONTEND/DASHBOARD.

O objetivo é que o dashboard mostre claramente que o sistema está realmente consumindo e utilizando as APIs externas.

NÃO quero apenas criar cards estáticos. Para as APIs que já estão funcionando, os dados exibidos no frontend devem vir das chamadas reais ao backend.

As integrações reais são:

1. Open-Meteo
2. Overpass API / OpenStreetMap
3. openrouteservice
4. OpenTopography

O SoilGrids é a exceção:

* NÃO fazer chamada real ao SoilGrids REST;
* usar dados ilustrativos/mockados;
* identificar claramente como "Demonstração" ou "Integração planejada".

==================================================

1. OPEN-METEO — CLIMA
   ==================================================

Criar/atualizar uma seção no dashboard:

"Condições Climáticas"

Mostrar dados REAIS vindos da API:

* temperatura atual;
* umidade relativa;
* precipitação;
* velocidade do vento;
* direção do vento;
* previsão de chuva;
* previsão de temperatura, se disponível.

Mostrar também:

Última atualização: [timestamp real da consulta]

Os valores não devem ser hardcoded.

Se o backend já possui um endpoint para clima, utilizar esse endpoint.
