==================================================

A auditoria anterior encontrou dois caminhos principais.

1. SCORE LEGADO

Função:
calculateScore(inputs)

Fluxo:
RiskInputs
→ cálculo de pontos por fator
→ soma
→ clamp 0–100
→ level
→ mainFactor

Interface aproximada existente:

  weather: Weather;
  waterDistance: WaterDistance;
  operationType: OperationType;
  historyAlertCount: number;
  inclinationDegrees: number;
  terrain: Terrain;
}

Resultado:

interface ScoreBreakdown {
  total: number;
  level: RiskLevel;
  parts: ScorePart[];
  mainFactor: string;
}

2. SCORE PONDERADO ATUAL

Função:

Pesos:

interface RiskWeights {
  climate: number;
  operational: number;
}

Default atual:

{
  climate: 50,
  operational: 50
}

Fluxo:

ScoreBreakdown
→ climateScore normalizado
→ operationalScore normalizado
→ climateContribution
→ operationalContribution
→ finalScore
→ level
→ dominantFactor

Resultado aproximado existente:

interface RiskResult {
  climateScore: number;

  operationalContribution: number;
  finalScore: number;
  level: RiskLevel;

}
